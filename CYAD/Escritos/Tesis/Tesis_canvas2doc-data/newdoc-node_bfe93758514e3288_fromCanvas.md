Retomando de nuevo los estudios de Burghardt (2005) y tomando com obase sus cinco puntos, establece cinco criterios para determinar lo que es un juego, y que son: 
1. La representación de la conducta no es meramente funcional, ni formal ni contextualmente. Este criterio establece una función inmediata limitada
2. El comportamineto es espontaneo, voluntario, autotélico. Este criterio apela al componente endógeno
3. Jugar se diferencía del comportamiento serio al ser incompleto, exagerado, torpe o precoz; implica patrones de comportamiento con forma, secuencia o destino modificados. Este criterio apela a una diferencia estructural o temporal
4. El comportamineto del juego se realiza de forma repetidamente similar, pero no estereotipada. Este criterio apela a una representación repetida
5. Jugar requiere que el animal esté bien alimentado, sano y libre de estrés. Este criterio apela a un campo relajado
